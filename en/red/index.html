NETWORK / PROTOCOL

An independent network.
Evidence before launch.

SYPcoin aims to build a public Proof-of-Work blockchain using an independently validated network, genesis, monetary rules and nodes. An initial native P2P handshake was verified without blocks; later v41.3 propagated and persisted one GPU-mined SYPcoin native block (height 1) across two private JVM nodes. Complete consensus and the public testnet are still pending. Historical Ergo devnet results are separate.

CORE DESIGN

How the network is intended to work.

A clear model requires each participant to be able to verify consensus-critical information.

POW

Verifiable work

Miners propose block candidates, while validating nodes independently check the proof, difficulty, rewards and all other required rules.

UTXO

Transaction outputs

Unspent transaction outputs represent spendable value under explicit conditions. Nodes validate the inputs, outputs and state transitions.

P2P

Open node communications

Nodes exchange announcements, blocks and transactions. A production network must handle incompatible peers, failures and reorganization safely.

How nodes agree on state.

LABORATORY

What has actually been observed.

Published milestones carefully distinguish local results from network releases.

CONFIRMED IN LAB

Two native JVM processes connected

The original v39 reciprocal handshake passed 30/30 focused tests with zero blocks. A later v41.3 private test successfully applied and persisted native block height 1 on both JVM nodes, without establishing full consensus.

CONSENSUS PENDING

Native block exchange and state

In v41.3 a native GPU-mined SYPcoin height-1 block was applied, propagated and persisted by both private JVM nodes. V41.4-R4 subsequently confirmed that historical height-2 block. Separately, private P0 H1–H3 were mined and both nodes recovered H3 after restarting. Complete consensus is unverified.

NOT AVAILABLE

Public network metrics

There is no verified SYPcoin public chain height, network hashrate, node list, explorer or API to display.

PUBLIC RELEASE REQUIREMENTS

Checks before opening a network.

Public participation requires reproducible, independently inspectable software and results.

A

Native genesis and monetary integrity

Ensure every node reproduces the same initial state and rejects incompatible blocks or incorrect issuance.

B

Node failure and reorganization

Check recovery, divergent chains, transactions under contention and bandwidth or resource limits.

C

Verifiable distribution

Publish appropriately reviewed software, checksums, documentation, security warnings and version compatibility rules.

Development status

SYPcoin has no operational public testnet or mainnet. Never treat local Ergo devnet blocks as public SYPcoin balances or rewards.

Network claims must be supported by nodes and evidence.
