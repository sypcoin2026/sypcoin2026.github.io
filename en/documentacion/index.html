What is actually public.

A successful experiment does not mean the software is ready for public use.

NODES

No public SYPcoin node package

Two local Ergo devnet nodes were synchronized, but an independent public SYPcoin client is not available.

MINER

GPU mining tools are being tested in the laboratory; no public SYPcoin pool or miner release is advertised.

FREQUENTLY ASKED QUESTIONS

Answers without exaggeration.

These answers reflect the current development phase.

Can I mine SYPcoin right now?

Not on a public SYPcoin network. There is no official downloadable miner, pool or testnet endpoint.

Is SYPcoin the same project as Ergo?

No. SYPcoin is independent and uses Ergo 6.0.8 as an experimental technical foundation. Ergo devnet is not a SYPcoin testnet.

Will the founders receive a premine?

The intended monetary model does not include a premine or founder allocation, but its final implementation still requires verification.

Is there a public testnet or mainnet?

No operational public SYPcoin testnet or mainnet is currently announced.

Where can I see the tests?

Visit development milestones and the evidence summaries. Raw private reports have not been published.

Have any charitable transfers occurred?

No verified public charitable movements are recorded. The 0.5% plus 0.5% model is a proposal awaiting implementation.

How can I contribute?

See Get involved for safe public feedback channels, limitations and scam prevention.

GLOSSARY

Essential technical terms.

These definitions clarify the difference between development and production.

POW

Proof of Work

Consensus based on computational work proposed by miners, subject to independent node validation.

UTXO

Unspent transaction output

An output that has not yet been spent under its validation conditions.

GENESIS

Initial chain state

The original state of a specific blockchain. An experimental Ergo devnet genesis is not SYPcoin's final genesis.

DEVNET

Development network

A local or controlled technical test environment.

TESTNET

Public test network

A separate test chain that external participants can operate under documented rules.

MAINNET

Production network

An operational public chain with real monetary and security consequences.

FRM

Mining Reward Fund

Experimental mechanism intended for long-term mining incentive studies.

ERGoTREE

ErgoTree contracts

Contract representation inherited from Ergo's technological foundation during SYPcoin experiments.

SYPcoin

Independent Proof-of-Work cryptocurrency project under development.
