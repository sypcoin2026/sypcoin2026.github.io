SYP / INDEPENDENT CRYPTOCURRENCY PROJECT

Proof of Work.
GPU mining.
Verifiable progress.

SYPcoin is an experimental independent cryptocurrency project. We are developing a modular protocol, GPU-oriented mining, security testing and verifiable monetary rules, using Ergo 6.0.8 as a technical foundation.

Development milestonesRead documentation
Important: pre-testnet laboratory stage

There is no operational SYPcoin public testnet, mainnet, official wallet or public mining service. Laboratory results based on Ergo devnet do not constitute a launched SYPcoin network.

DOCUMENTED PROGRESS

Two native JVM processes connected.
Consensus and GPU mining still pending.

Two native SYPcoin JVM processes completed a real local P2P handshake without blocks (30/30 focused tests). Encrypted-custody issuance signing passed 10/10 offline tests, partial consensus checks remain under test, and a read-only GPU monitoring tool passed 6/6 offline tests. No valid native PoW block has yet been accepted by both nodes.
