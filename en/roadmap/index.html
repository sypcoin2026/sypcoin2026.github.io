RELEASE CRITERIA

Build. Test.
Release only when justified.

The roadmap is driven by verifiable acceptance criteria, not promised launch dates. Passing a component test does not automatically complete an entire security or consensus phase.

FOUR PHASES

A roadmap of technical outcomes.

Status descriptions are not deadlines or declarations that the project is ready for investment.

01 / LAB

Monetary components

Accounting, experimental genesis, ErgoTree and emission-related UTXO tests have documented local results.

02 / CURRENT

Independent protocol integration

In v41.3 an AMD RX 7900 XTX/Linux mined native SYPcoin block height 1, which two private JVM nodes accepted and persisted. V41.4-R2 signed the height-2 candidate offline and R3 passed 10/10 focused tests; the second block is NOT mined or accepted. Full consensus and Windows/NVIDIA compatibility are pending.

03 / FUTURE

Public testnet

Enable third-party nodes, reproducible client setup and publicly verifiable test mining.

04 / FUTURE

Mainnet

Consider launch only after security, monetary rules and essential user tools satisfy explicit requirements.

CROSS-PLATFORM PLAN · NOT CERTIFICATION

GPU and OS testing in sequence.

Validate the miner first, then the optional external optimizer. AMD/Linux lab-verified → AMD/Windows → NVIDIA/Windows → NVIDIA/Linux and later Intel. No public mining download is available. Full compatibility roadmap.

PUBLIC TEST NETWORK

Minimum checks before opening.

The purpose of a testnet is to exercise a defined system in a wider, controlled environment.

CONSENSUS

Native chain rules

An independent genesis and reproducible emission rules must be enforced by all participating nodes.

NODES

Reproducible synchronization

Multiple independent machines should connect, recover from interruptions and reject invalid data.

GPU

Verified mined blocks

A mining program should produce new candidate blocks accepted by independent validating nodes.

RELEASE

Traceable software

Versioned source, binaries when authorized, checksums and compatible documentation should be provided.

SAFETY

Negative and stress tests

Exercise malformed transactions, invalid blocks, reconnections, adversarial conditions and resource limits.

OBSERVABILITY

Public evidence

Provide trustworthy network state and test results rather than placeholder chain metrics.

PRODUCTION CHECKS

Mainnet requires additional assurance.

An operational testnet alone is not proof of production readiness.

ECONOMICS

Final monetary invariants

Verify the supply, emission curve, allocation rules and legitimate mining process.

SECURITY

Auditable controls

Evaluate risks, resolve defects, document procedures and seek external review as appropriate.

USABILITY

User-critical tools

Provide reviewed wallet/custody options, node distribution and documentation for safe participation.

UPDATES

Protocol maintenance

Document backwards-compatible changes and conflict resolution without falsely promising that hard forks will never be necessary.

ACCOUNTABLE COMMUNICATION

Publish work with clear limitations.

We will not convert a local PASS into a public launch announcement.

REPORTED

Date and scope

Record the component, date, outcome and precise environment of each milestone.

EVIDENCE

Only genuine public links

Publish audited-for-privacy reports when actually accessible, not local filesystem paths or invented checksums.

NO COUNTDOWN

No fixed release date

Neither a public testnet nor mainnet launch date is announced until the acceptance criteria support that decision.

Development stage remains red

No announced public testnet or mainnet currently exists. Roadmap stages and descriptions are objectives rather than releases completed in the independent SYPcoin network.
