PRIVACIDAD

Una web pública.
Datos mínimos.

La web oficial de SYPcoin no solicita registro, acceso a wallets ni datos financieros a sus visitantes.

Alojamiento y estadísticas

Esta web se aloja en GitHub Pages y utiliza Cloudflare Web Analytics para conocer visitas y rendimiento. Según Cloudflare, su producto Web Analytics no recopila ni utiliza datos personales de los visitantes. No se han instalado sistemas propios de identificación de usuarios.

Enlaces externos

Al abrir GitHub u otros servicios ajenos, se aplican las condiciones y políticas de esos sitios. El código público del sitio está disponible en GitHub.

Datos sensibles

Los resultados públicos se redactan sin credenciales, claves privadas, rutas locales de laboratorio ni datos personales que no sean necesarios. Los futuros justificantes solidarios deberán proteger la información sensible de las personas beneficiarias.

Correcciones

Para avisar de un enlace roto o un problema de contenido, puedes abrir una incidencia pública. No publiques información confidencial en incidencias abiertas.
