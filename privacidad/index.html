PRIVACIDAD

Una web pública.
Datos mínimos.

La web no crea cuentas ni solicita claves, datos bancarios o acceso a wallets. Quien quiera recibir un único aviso de apertura de la testnet puede facilitar voluntariamente su correo electrónico.

Alojamiento y estadísticas

Esta web se aloja en GitHub Pages y utiliza Cloudflare Web Analytics para conocer visitas y rendimiento. Según Cloudflare, su producto Web Analytics no recopila ni utiliza datos personales de los visitantes. No se han instalado sistemas propios de identificación de usuarios.

Aviso voluntario de apertura de testnet

Responsable del tratamiento: gestión del proyecto SYPcoin; contacto: sypcoin@proton.me. Dato recogido: dirección de correo del interesado y declaración de consentimiento. Finalidad: un único mensaje de apertura cuando exista una testnet pública. No utilizaremos la dirección para publicidad ni la publicaremos en GitHub. La inscripción no garantiza plaza.

Base jurídica: consentimiento libre y específico, mediante casilla sin marcar inicialmente. Recepción: Web3Forms tramita el envío automático y lo reenvía al buzón privado; puede aplicar controles anti-spam. Como alternativa, la persona puede enviar la solicitud desde su propia aplicación de correo directamente a ese buzón, sin usar Web3Forms. Una solicitud fallida o no entregada no debe considerarse una inscripción confirmada. No se ha implementado confirmación de titularidad del correo. Conservación prevista bajo control del proyecto: hasta el envío del aviso y un máximo de 30 días más, salvo retirada anterior; Web3Forms puede retener temporalmente las solicitudes conforme a sus propias condiciones.

Derechos y baja: escribe a sypcoin@proton.me para retirar el consentimiento, consultar los datos o solicitar rectificación o supresión. Agencia Española de Protección de Datos. La persona responsable del proyecto debe completar y revisar la información identificativa y contractual aplicable antes de considerar este aviso una política RGPD definitiva.

Enlaces externos

Al abrir GitHub u otros servicios ajenos, se aplican las condiciones y políticas de esos sitios. El código público del sitio está disponible en GitHub.

Datos sensibles

Los resultados públicos se redactan sin credenciales, claves privadas, rutas locales de laboratorio ni datos personales que no sean necesarios. Los futuros justificantes solidarios deberán proteger la información sensible de las personas beneficiarias.

Correcciones

Para avisar de un enlace roto o un problema de contenido, puedes abrir una incidencia pública. No publiques información confidencial en incidencias abiertas.
